
# SaveForX – Free Twitter (X) Video Downloader

[SaveForX](https://saveforx.com/) is a free online Twitter (X) video downloader that helps users save publicly accessible videos directly from their browser.

## Features

- Download publicly accessible Twitter (X) videos.
- HD video downloads up to 1080p when available.
- Extract audio in MP3 format.
- Simple and user-friendly interface.
- No registration required.
- No software installation required.
- Works on desktop and mobile browsers.

## How to Use SaveForX

1. Open Twitter (X).
2. Copy the URL of a public post containing a video.
3. Visit https://saveforx.com/
4. Paste the post URL.
5. Choose an available download option.
